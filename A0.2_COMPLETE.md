## How It Works (Simple Explanation)

### Before Docker:
```
Your computer: Python + FastAPI + SQLite
Problem: "Works on my machine" — might not work on someone else's
```

### With Docker:
```
Your computer
     ↓
  Docker Container (sealed environment)
     ├── Python 3.10 (guaranteed)
     ├── FastAPI (same version everywhere)
     ├── SQLite (same version everywhere)
     └── Your code (live reloads)
     
Beta team's computer
     ↓
  Same Docker Container (exactly the same)
     ├── Python 3.10 ✅
     ├── FastAPI ✅
     ├── SQLite ✅
     └── Your code ✅
```

## What Docker Compose Does

1. **Reads `Dockerfile`** → creates a Docker image (blueprint)
2. **Reads `docker-compose.yml`** → starts 2 containers:
   - `api` container (FastAPI server)
   - `db` container (SQLite database)
3. **Port mapping:** `localhost:8000` → FastAPI inside container
4. **Volume mapping:** Your code folder → `/app` inside container
   - When you edit `api/main.py`, FastAPI restarts automatically
   - Database files persist in `./db` folder

## Key Concepts

| Concept | Explanation |
|---------|---|
| **Docker** | Container technology (like VM, but lighter) |
| **Image** | Blueprint (from `Dockerfile`) |
| **Container** | Running instance of an image |
| **Volume** | Folder mapping (your PC ↔ container) |
| **Port mapping** | Network mapping (localhost:8000 ↔ container:8000) |
| **docker-compose** | Orchestrates multiple containers together |
